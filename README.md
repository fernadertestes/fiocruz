# Mapa Vivo — Fiocruz Rio

Protótipo responsivo da página institucional da Fiocruz Rio, com o Campus Manguinhos como elemento central.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run lint
npm run build
```

O protótipo inclui mapa aéreo otimizado com preload, conteúdo semântico, navegação responsiva, busca expansível, controles de leitura/contraste, zoom do mapa e preferência por movimento reduzido.

Cinco pontos do mapa carregam amostras 3D sob demanda. No desktop, passe o cursor ou navegue com a tecla Tab; no celular, toque em um ponto. Os modelos otimizados para web ficam em `public/models`, enquanto os arquivos-fonte pesados são preservados localmente em `source-models` e ignorados pelo Git.
